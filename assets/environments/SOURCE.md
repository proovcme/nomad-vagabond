# Lighting environment

`environmentSpecular.env` is the default prefiltered HDR environment used by Babylon.js's `createDefaultEnvironment`.

Source: https://assets.babylonjs.com/environments/environmentSpecular.env
Documentation: https://doc.babylonjs.com/features/featuresDeepDive/materials/using/HDREnvironment
Downloaded 2026-11-14. Runtime uses the local file, without external requests.
